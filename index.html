Learn how to generate useful image variations

Hold the art direction steady

Recipes are repeatable prompt bundles: pastel illustration, hard-edge screenprint, pixel art, oil realism, ornamental miniature art, and project icons. Pick up to three for one subject and apply one of seven fixed color palettes across the run. Recipes guide the prompt so the look stays consistent, but they are not trained style models, so results will still vary.

  • Compare several styles against the same subject.
  • Keep the palette fixed while composition changes.
  • Add reference images when text alone is not enough.
  • Use Custom mode when you want full prompt control.

Images and round project icons

Choose a standard image for editorial art, presentations, concepts, backgrounds, or site assets. Choose the project-icon family when you need a compact square composition that survives a circular crop.

For project icons, BYOBanana can turn a square generated image into a circular PNG with transparent corners, exported at 512 by 512, 256 by 256, or the source's full resolution. The source image is clipped to a full-bleed circle.

This is raster icon output. It is not an editable SVG, vector logo, brand kit, or trademark review.

How it works

1. Add a Google AI Studio key

Open the key panel, paste your key, and validate it against Google's model list. Remembering the key is optional and off by default.

2. Set up a comparison run

Describe the subject. Choose images or a round project icon, one to three recipes, a color palette, optional references, model settings, and the number of variants.

3. Review cost, generate, and compare

Check the estimate before generation. Watch candidates fill the contact sheet, inspect the strongest options, and select the files you want.

4. Export the keepers

Download selected outputs as a ZIP. The bundle includes a text manifest with the model settings, rendered prompts, recipes, palette, and file hashes used for that run.

Frequently asked questions

What is Nano Banana?

Nano Banana is Google's name for the native image generation models in the Gemini API. BYOBanana is an independent, browser-based Nano Banana image generator built on selected Gemini image models. It is not affiliated with or endorsed by Google.

Is BYOBanana free?

BYOBanana does not charge a subscription or sell image credits. Image generation uses your Google API key, and Google API charges may apply. BYOBanana shows an estimated run cost before generation.

Do I need an account?

You do not need a BYOBanana account. You do need a Google account, a Google AI Studio API key, and access to a supported Gemini image model.

Is BYOBanana a private AI image generator?

It has a limited privacy advantage: prompts, images, and the key are not routed through a BYOBanana application server. They are sent directly from your browser to Google, and Google processes them under the terms for your API tier. Sessions and images are also stored locally in your browser. It is not offline or fully private.

Where is my API key stored?

The key stays in browser memory unless you turn on Remember. Remember stores it as plaintext in localStorage on this device. Any script running on the same site origin could potentially read it, so do not remember a key on a shared device.

Can it create image variations from a reference image?

You can add reference images to a run and generate several candidates from the same brief. BYOBanana also supports prompt-first batches where every candidate starts from the same subject, style recipe, and palette.

Does it make logos?

BYOBanana can explore raster visual concepts and export round project icons. It does not currently create editable vector logos, typography systems, brand kits, or trademark-ready files.

Are generated images watermarked?

Google states that images generated by its current Nano Banana models include SynthID. BYOBanana does not remove or bypass it.
